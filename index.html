Install the frame firmware.

Chrome on this computer, with the EE02 plugged in by a USB data cable. This install keeps Wi-Fi. After the splash, the frame downloads today's picture. Erase only if the installer asks on a board that has never run Wally.

Use Chrome or Edge on a computer. This browser cannot reach the USB port. Open this page at https://pixelwave.github.io/wally-firmware/ so Chrome can use the USB port.
  1. Plug the frame into this computer. If no port appears, hold BOOT, tap RESET, then release BOOT and click the button again.
  2. Choose the USB serial device and let the erase finish.
  3. After erase, the panel shows a QR code. Join Wally-Setup, open the page, and enter Wi-Fi, the Wally address, and the Wally password. The Home Assistant key is under Advanced.
The refresh takes about 30 seconds and the panel may whine. That sound is the panel supply.
